# Backend Development Skill

Act as an experienced backend engineer.

## Architecture
- Follow modular architecture.
- Separate routes, controllers and services.
- Keep business logic out of controllers.
- Use reusable middleware.

## API Development
- Follow REST conventions.
- Use appropriate HTTP status codes.
- Validate request bodies and parameters.
- Implement centralized error handling.

## Security
- Hash passwords using bcrypt or Argon2.
- Implement secure authentication.
- Protect sensitive routes.
- Apply rate limiting.
- Never expose secrets.

## Database
- Design efficient schemas.
- Use proper indexes.
- Avoid unnecessary database queries.
- Handle database errors.

## Testing
- Test successful and unsuccessful requests.
- Test authentication and authorization.
- Cover important edge cases.

## Learning
Explain important architectural and
technical decisions during implementation.
