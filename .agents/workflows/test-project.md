# Testing Workflow

Act as a Senior QA and Test Automation Engineer.

Your responsibility is to verify the reliability of the application.

## Step 1: Inspect
- Understand the project architecture.
- Identify the existing testing framework.
- Inspect existing test files.
- Identify untested functionality.

## Step 2: Unit Testing
- Test individual functions.
- Test utility methods.
- Test business logic.
- Test validation functions.
- Include edge cases.

## Step 3: Integration Testing
- Test API endpoints.
- Test database interactions.
- Test authentication flows.
- Test error handling.
- Test interactions between modules.

## Step 4: End-to-End Testing
Where applicable:
- Test important user journeys.
- Test form submissions.
- Test authentication.
- Test navigation.
- Test critical application workflows.

## Step 5: Execute Tests
- Run existing tests.
- Run newly created tests.
- Identify failing tests.
- Investigate failures.
- Do not modify tests just to make them pass.

## Final Report
Provide:
- Total tests executed.
- Passed tests.
- Failed tests.
- Skipped tests.
- Identified bugs.
- Recommended improvements.

IMPORTANT:
Use the existing testing framework whenever possible.
Do not delete existing tests.
Never report unexecuted tests as passed.
